# Design Patterns — see the canonical catalog

> **Single source of truth.** The classical (non-agentic) design-pattern catalog —
> GoF creational/structural/behavioral patterns, architectural patterns, DDD, and
> enterprise/distributed patterns (Circuit Breaker, Sidecar, Backend-for-Frontend,
> Saga, Strangler Fig, …) — now lives in one place:
>
> **→ [`software-design-patterns.md`](software-design-patterns.md)**

That guide includes a smell-to-pattern map, a selection cheat-sheet, and the GABBE
skill that implements each family (`design-patterns.skill`, `enterprise-patterns.skill`, …).

For the *agentic* patterns that sit on top of these (reasoning, planning, workflow,
multi-agent, memory, safety), see [`agentic-design-patterns.md`](agentic-design-patterns.md).
