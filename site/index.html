GABBE

Generative Architectural Brain Base Engine · Agentic Software R&D Engineering Kit · v1.1.2

An open-source Markdown kit that turns AI coding agents into a governed engineering team, for any project type, language and team size.

What it does

  • Gives AI coding agents context, skills, memory and workflows, with software development cycle gates and human-in-the-loop checkpoints.
  • Works with Claude Code, Cursor, Windsurf, Cline, Aider, Devin, Gemini, Antigravity, OpenCode, Zed, Continue, Roo Code, Kilo Code, OpenAI/Codex, GitHub Copilot and VS Code; it writes each tool's native skill format.
  • Covers a lifecycle from Day-0 strategy and discovery (S00) through the S01–S10 development gates to Day-2 operate, evolve and decommission (S11–S13), with spec-driven and test-driven development.
  • Includes an evals and guardrails layer mapped to OWASP LLM Top 10, NIST AI RMF, MITRE ATLAS, ISO 42001 and the EU AI Act. It documents coverage; it is not a certification.
  • Ships 214 skills, 100 templates, 86 guides, 36 personas and 50+ MCP server configurations.
  • Optional experimental Python CLI (gabbe) for budgets, policy, audit tracing, an MCP gateway, gabbe doctor and gabbe verify.

Install

npx gabbe-kit init
npx gabbe-kit init --agents claude,cursor,antigravity,opencode --yes
curl -fsSL https://raw.githubusercontent.com/andreibesleaga/GABBE/main/install.sh | sh
pipx install gabbe

The first command is the Python-independent kit installer; the second is its non-interactive form; the third is a shell bootstrap. pipx install gabbe installs the gabbe CLI only, not the kit. On npm the package is gabbe-kit; on PyPI it is gabbe. Run gabbe doctor afterwards for an environment and install report.

As Claude Code plugins:

claude plugin marketplace add andreibesleaga/GABBE
claude plugin install gabbe@gabbe

Both installers back up any differing existing file to <name>.gabbe-bak before refreshing it. Full guide: docs/INSTALL.md.

Key concepts

Skills, templates, guides, personas
Markdown building blocks under agents/, compiled into each agent's native format.
AGENTS.md and CONSTITUTION.md
The operating loop for each session and the hard rules (security, cost, spec-driven work, observability, human approval) that agents follow.
Spec-driven lifecycle
Spec, evals, tests, then code, with human approval gates between phases.
Brain Mode (experimental)
A meta-cognitive layer using an Active Inference loop (predict, act, observe, compare, adapt), cost routing between local and remote models, and episodic memory. Its outputs are advisory, not production guarantees.
Loki Mode (experimental)
A multi-agent team of 30+ specialised roles for large projects, with memory, history auditing and checkpoints.
Fail-closed guardrails
Agents wait for human approval rather than bypass a guardrail; the optional CLI gateway denies by default without a policy.
